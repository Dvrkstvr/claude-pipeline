# Lessons

Cross-project lessons: true for **every** project on a stack or approach, learned
the hard way in one of them. Read on demand by the feasibility scout and the
architect (they look for files matching the project's stack and approach); never
loaded into a session by default.

- One file per stack or approach: `expo-react-native.md`, `dotnet.md`,
  `design-first.md`, `p2p.md`, …
- One bullet per lesson: the rule, then *why* in one clause, then the project it
  came from. ≤ 60 lines per file — merge or drop before adding.
- Written only by the curator **after the user agrees** (it changes every future
  project).

Lesson files are personal and gitignored in the published repo: each user grows
their own from their own projects, starting from this empty folder.

Project-specific lessons do not belong here — they go into that project's
code comments, path-scoped rules or `docs/decisions/`.
